# Welcome to HyperLED! 🚀

**HyperLED** is an open-source firmware for controlling addressable LED strips and LED matrices, tailored for the **ESP32-S3**.

## What does HyperLED offer?

HyperLED combines a fast, visually striking web interface with a robust Master/Slave architecture that keeps multiple controllers perfectly in sync – from a single LED strip up to a large HUB75 matrix installation.
