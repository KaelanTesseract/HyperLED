## Overview
HyperLED is an advanced, high-performance LED controller firmware based on the **ESP32-S3**. It offers a beautiful glassmorphism WebUI, an Android Companion App, wired Master/Slave serial synchronization (HyperBus), and deep customization.

HyperLED ist eine moderne, hochperformante LED-Controller-Firmware für den **ESP32-S3**. Sie bietet eine wunderschöne Web-Oberfläche im Glassmorphism-Design, eine Android Companion App, Master/Slave Synchronisation über eine kabelgebundene serielle Verbindung (HyperBus) und tiefgreifende Anpassungsmöglichkeiten.

### Key Features
- **Modern WebUI:** Responsive glassmorphism interface.
- **Android App:** Native app with mDNS auto-discovery and quick controls.
- **Master/Slave Sync:** Sync multiple ESP32 controllers with sub-millisecond precision via a high-speed wired serial bus (HyperBus).
- **OTA Updates:** Full dual-partition (Firmware + LittleFS) Over-The-Air updates.
- **Segments & Palettes:** Split your strips into dynamic segments and map pixel art directly.
- **Smart Home Ready:** Fully configurable MQTT integration.
