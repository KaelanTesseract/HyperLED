## Überblick
HyperLED ist eine moderne, hochperformante LED-Controller-Firmware für den **ESP32-S3**. Sie bietet eine wunderschöne Web-Oberfläche im Glassmorphism-Design, Master/Slave-Synchronisation über eine kabelgebundene serielle Verbindung (HyperBus) und tiefgreifende Anpassungsmöglichkeiten.

### Wichtigste Funktionen
- **Moderne Web-Oberfläche:** Responsives Glassmorphism-Design.
- **Master/Slave-Synchronisation:** Mehrere ESP32-Controller mit unter einer Millisekunde Präzision über einen schnellen kabelgebundenen seriellen Bus (HyperBus) synchronisieren.
- **OTA-Updates:** Vollständige Over-The-Air-Updates mit doppelter Partition (Firmware + LittleFS).
- **Segmente & Paletten:** LED-Streifen in dynamische Segmente aufteilen und Pixel-Art direkt einbinden.
- **Smart-Home-fähig:** Vollständig konfigurierbare MQTT-Integration.
