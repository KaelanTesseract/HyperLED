Matrix-Vorschau

Zeigt live, was gerade auf dem Panel läuft (nur Master-Matrix).

Matrix Inhalt

Ziehe ein Element in der Vorschau oben an die gewünschte Position. Ein Hintergrundbild zählt auch als Element.

Standort für Wetter-Element

Nötig für das Wetter-Element (aktuelle Temperatur + Symbol).

Hintergrundbild hochladen

Wähle ein Bild aus. Es wird automatisch an deine Matrix-Größe angepasst und als Hintergrund-Element übernommen.

Hintergrundbild malen

Male dein eigenes Bild direkt im Raster deiner Matrix und übernimm es als Hintergrund-Element.

2D Matrix Setup

Leinwand: Slave-Panels

Ordnet Slave-Matrizen relativ zur Master-Matrix an (oben-links = 0,0), damit 2D-Effekte (Plasma, Fire 2D, Ripple, Pacifica, Matrix Rain) nahtlos über alle Panels laufen.
